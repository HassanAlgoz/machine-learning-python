This course is a practical introduction to applied machine learning with scikit-learn.
You will progress from linear models and feature preprocessing, through model evaluation and classification, to tree-based methods and modern explainable AI techniques. Along the way, you will work through hands-on notebooks, coding exercises, and interactive widgets that help you build an intuition for how models behave in practice.

Module 1: Linear Models

Module 1 builds the foundations of supervised learning using linear models for regression and classification. You will learn how to represent data with features, fit linear models, interpret their parameters, and understand when linear assumptions are reasonable.

Key Terms:

  • supervised learning, data matrix, features, targets
  • linear regression, logistic regression
  • model coefficients, intercept, decision boundary
  • non-linear relationships via feature engineering

Module 2: Pipelines

Module 2 focuses on data preprocessing and modeling pipelines. You will learn how to handle missing values, scale numerical features, encode categorical variables, and chain these steps together with estimators into reusable, production-ready pipelines.

Key Terms:

  • imputation, missing values
  • feature scaling, normalization, standardization
  • categorical encoding, one-hot encoding, ordinal encoding
  • scikit-learn transformers, estimators, pipelines
  • regression metrics (R², MSE, MAE)

Module 3: Model Selection and Evaluation

Module 3 deepens your understanding of generalization and model selection. You will practice splitting data into training, validation, and test sets, detect underfitting and overfitting, and use cross-validation and hyper-parameter tuning to select robust models.

Key Terms:

  • training/validation/test splits, cross-validation
  • loss functions vs evaluation metrics
  • baseline models (DummyClassifier, DummyRegressor)
  • underfitting, overfitting, bias–variance trade-off
  • hyper-parameter tuning, grid search, randomized search, nested CV
  • stratified cross-validation, grouped cross-validation

Module 4: Classification

Module 4 introduces classification-specific evaluation and validation techniques. You will explore stratified and grouped cross-validation, work with common classification metrics, and learn how thresholds and probability calibration affect decision-making.

Key Terms:

  • classification metrics: accuracy, precision, recall, F1, ROC–AUC
  • confusion matrix, precision–recall trade-off
  • decision thresholds, score calibration

Module 5: Decision Trees and Ensembles

Module 5 focuses on decision trees, ensemble methods (bagging, random forests, boosting), and wraps up with an introduction to explainable AI (SHAP). You’ll learn how trees make predictions, how ensembles reduce variance and boost performance, and how to interpret complex models with feature importance and SHAP explanations.

Key Terms: - decision trees, splits, tree depth, leaves
- regression trees, classification trees
- overfitting with deep trees, pruning
- bagging, random forests, boosting (gradient boosting, AdaBoost)
- ensembles of trees
- SHAP, feature contribution, explainability
