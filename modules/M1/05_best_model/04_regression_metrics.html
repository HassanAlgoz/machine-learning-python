مثال عملي: كيف نقيس أداء نموذج يتنبأ بأسعار المنازل (بالدولار)؟

from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
from sklearn.linear_model import LinearRegression
import numpy as np

# تدريب نموذج انحدار وهمي للتوضيح (بافتراض وجود X_train, y_train, X_test)
model = LinearRegression().fit(X_train, y_train)
y_pred = model.predict(X_test)

# 1. متوسط الخطأ المطلق (MAE) - يعطينا الخطأ الفعلي بمتوسط عدد الدولارات
mae = mean_absolute_error(y_test, y_pred)
print(f"MAE: ${mae:,.2f}")

# 2. جذر متوسط مربع الخطأ (RMSE) - يعاقب الأخطاء الكبيرة بشدة
rmse = np.sqrt(mean_squared_error(y_test, y_pred))
# أو في الإصدارات الحديثة من sklearn: root_mean_squared_error(y_test, y_pred)
print(f"RMSE: ${rmse:,.2f}")

# 3. معامل التحديد (R2 Score) - نسبة التفسير (أعلى = أفضل، 1 ممتاز، 0 سيء)
r2 = r2_score(y_test, y_pred)
print(f"R^2 Score: {r2:.3f}")

بلغة بسيطة: نستخدم MAE لأن فهمه سهل للمدراء (مثلاً: النموذج يخطئ بـ 5000 دولار في المتوسط). نستخدم RMSE عندما نريد الانتباه بشدة للأخطاء الفادحة (outliers). ونستخدم \(R^2\) لنفهم ما إذا كان النموذج أفضل من مجرد توقع متوسط الأسعار للجميع.

ملاحظة: في دوال التحقق المتقاطع (CV)، نستخدم المصطلحات السلبية مثل neg_mean_squared_error لأن تلك الدوال تفترض دائماً أن “القيمة الأعلى تعني أداءً أفضل”.

معامل التحديد (Coefficient of Determination, \(R^2\))

تشبيه: \(R^2\) يجاوب: “ما نسبة تغيّر \(y\) الذي يفسره النموذج؟” خط أساس بسيط هو التوقع بمتوسط \(y\). \(R^2 = 1\) يعني أن النموذج يطابق البيانات تماماً (في عينة التقييم)، و\(R^2 = 0\) يعني أن النموذج لا يزيد عن التوقع بالمتوسط.

تقني: \[R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}.\] يمكن أن يكون سالباً إذا كان النموذج أسوأ من التوقع بالمتوسط. نفس ترتيب النماذج يعطيه MSE (أو neg_MSE)؛ \(R^2\) أسهل تفسيراً كـ “نسبة التفسير”.

تحليل الخطأ ورسم البواقي (Residual plot)

تحليل الخطأ ورسم البواقي (Residual plot)

مثال عملي: هل يخطئ النموذج أكثر كلما زاد السعر الفعلي للمنزل؟ الرسم البياني للبواقي يكشف ذلك.

import matplotlib.pyplot as plt
from sklearn.metrics import PredictionErrorDisplay

fig, ax = plt.subplots(figsize=(8, 6))

# استخدام دالة جاهزة من sklearn لرسم البواقي
PredictionErrorDisplay.from_predictions(
    y_true=y_test, 
    y_pred=y_pred, 
    kind="residual_vs_predicted", 
    ax=ax, 
    scatter_kwargs={'alpha': 0.5}
)

plt.title("Residuals vs. Predicted Values")
plt.show()

ماذا نبحث في هذا الرسم؟ - النموذج المثالي: النقاط متناثرة بشكل عشوائي تماماً حول خط الصفر \(0\). - خطأ التحيز: إذا كانت أغلب النقاط فوق الخط أو تحته، فالنموذج يميل لتقدير الأسعار بأقل أو بأكثر من الحقيقة دائماً. - مشكلة التباين غير الثابت (Heteroscedasticity): إذا شَكّلت النقاط شكلاً يشبه “المخروط” (تزداد المسافة بين النقاط كلما اتجهنا يميناً)، فهذا يعني أن ثقة النموذج وفعاليته تقل بشكل ملحوظ عندما تكون التوقعات عالية القيمة.

خلاصة

المقياس الاستخدام
MSE / neg_MSE تدريب وتقييم؛ حساس للقيم الشاذة
MAE / neg_MAE تقييم عندما نريد خطأً أقل حساسية للشواذ
\(R^2\) تقرير “نسبة التفسير”؛ بلا أبعاد
رسم البواقي تشخيص تحيز، تباين غير ثابت، علاقات غير ملوّنة
